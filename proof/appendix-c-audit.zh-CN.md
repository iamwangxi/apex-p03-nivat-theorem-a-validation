## 1. Remark 3.1′ 与 C.3：原例不足以支持完整 A 的反例声明

来源位置：Remark 3.1′，p.11；C.3，p.32，均指[官方 PDF](https://math.apexin.net/papers/convex-nivat.pdf)。

该例取 $`p=2`$，$`v_1=(1,0),v_2=(0,-1),v_3=(1,-1)`$，左尾全零，右尾为 $`R_1=\mathbf1[x\text{ is even}]`$、$`R_2=R_3=\mathbf1[3\mid x]`$。所有尾场均仅依赖 x。

第二个分量的法向坐标是 x；宽度为一的过渡条带内取常数 1，因此该分量本身也只依赖 x。它的隔离背景是其他分量的尾场之和，仍只依赖 x。因此该方向的全部异常差分场被 $`T^{(0,-1)}`$ 保持，只可能出现频率 1；非双周期假设和 Lemma 2.1 保证至少一个差分非零，故

```math
\Lambda_2=\{1\},\qquad A_2(T^{v_2})=T^{(0,-1)}-1.
```

任意八种尾组合 $`\Theta_\epsilon`$ 及其全部颜色指标都只依赖 x，因此 $`A_2e_{\Theta_\epsilon}=0`$。完整 A 是所有方向因子的乘积，这些算子交换，所以

```math
Ae_{\Theta_\epsilon}=0\qquad\text{for all eight combinations.}
```

C.3 对单因子 $`A_1=T^{(2,0)}-1`$ 的计算仍然正确。所用混合差场取值为 $`(-1,0,1,0,1,0)`$，按 $`x\bmod6`$ 排列，施加 $`A_1`$ 后为 $`(2,0,0,0,-2,0)`$，确实非零。它说明这个单因子不足，不能据此推断完整乘积 A 不足。

**分开记录两项判定：**

- **原例不支持所声称的完整 A 反例：已确认。** 这是 A 与单因子 $`A_1`$ 的混淆；不是浮点精度造成的问题。
- **一般推广是否成立：未判定。** 尤其在正文自 §1 起采用的 Case B 范围内，本轮不证明也不否定任意尾组合的推广。删去 Case B 的变体不能冒充正文命题的反例；“例子失效”也不推出“一般推广成立”。

主证明只需要实际出现的 $`2m`$ 个扇区，已在 [上游证明](upstream-proof.md) §5 重建。因此这一局部说明错误不影响本轮定理 A 证明，不标为疑似重大漏洞。

此前精确审计检查了全部 8 组、6 个横向相位和两种颜色。纵向不变性来自上面的解析定义，不以有限 y 采样代替。完整 A 的消去只需其 $`A_2`$ 因子，不必重建其他因子。这一解析论证不需要私有运行日志。

## 2. Observation C.1 的条件和判据

Observation C.1（pp.31–32）限于 $`m=2`$、$`L_i=R_i`$。写 $`\delta_i=F_i-L_i`$，它有界宽条带支撑。将合法周期 $`H_1,H_2`$ 分别放大，使它们对另一条带的法向位移超过其宽度；这种放大不改变 Case A/B，见主证明 §2.3。

在四点模板上，$`\delta_1`$ 沿 $`H_1`$ 不变，$`\delta_2`$ 沿 $`H_2`$ 不变，而且各自在横穿其条带的一对位置中至多一处非零。背景 $`L_1+L_2`$ 在四角一致。如果两个差分都在同一个模板中出现，则某个角点同时有两个非零偏离 $`\alpha,\beta`$；反过来一个同时偏离点也给出这样的模板。

相应颜色向量差分（或其负号）为

```math
e_{b+\alpha+\beta}-e_{b+\alpha}-e_{b+\beta}+e_b.
```

当 $`\alpha,\beta\ne0`$ 时，颜色 b 的系数为 $`1+\mathbf1[\alpha+\beta=0]>0`$。这里系数在特征零中，所以包括 $`p=2`$ 也不会把系数 2 消去。因此 Case B 当且仅当 $`\mathop{\mathrm{supp}}\nolimits\delta_1\cap\mathop{\mathrm{supp}}\nolimits\delta_2=\varnothing`$。这个判据的指定条件下论证闭合。

## 3. 数值实验能支持什么

本轮只审读 C.1–C.2 的声明，不复跑随机种子，也未独立核验其所称全部 570 个分量的辅助精确输出。

| 声明类型 | 本轮判定 |
|---|---|
| 两个方框的模式数相同 | 只是观察稳定；不足以证明全局穷尽。附录已明确这一限制 |
| 模素数的采样矩阵秩 | 给出全局有理秩的下界；不能单凭两个模秩的差得到完整商空间的增量 |
| 有限框内 $`DI_a`$ 非零 | 可证明 Case A |
| 有限框内每个 $`DI_a`$ 均为零 | 只有框覆盖已证明的全部支撑才可判为 Case B；附录声称有补充精确核对，本轮不冒称逐项复现 |
| DFT 谱及随机单射编码 | DFT 阈值只给数值估计；单射不自动保谱。附录声称另有精确余式核对，本轮不把声明当独立证书通过 |
| 极小的周期残差 | 不能证明全局 $`A\eta=b_\eta`$；本轮由有限异常余项与 Laurent 注入性证明 |

本轮复用的 347/401 个全局模式实例有独立的锚点覆盖、完整 J 支撑和有理秩上下界证书，证据强度与附录一般的有限框实验不同。复核这些旧证书没有增加随机样本覆盖，也不改变附录 C.3 的判定。
